# 중·고등학생 관점 기준선 감사

작성일: 2026-09-23
프로젝트: painting-conservation-lab
모드: full 기준선 감사와 계획. 요청 범위가 개선점 탐색이므로 소스 구현은 하지 않았습니다.
실행 URL: http://127.0.0.1:5173/ (로컬 Vite 미리보기)

## 대상과 방법

실제 학생 연구가 아닌 모의 학습자 패널을 사용했습니다.

- 중학생 관점: 버튼을 먼저 누르는 학습자, 보존 용어에 아직 익숙하지 않을 수 있는 경우를 가정했습니다.
- 고등학생 관점: 증거와 한계를 함께 읽고, 표가 실제 판단 입력을 요구하는지 확인하는 경우를 가정했습니다.
- 교사 관점: 30분 수업에서 예측→조사→증거→결정→보고가 학생 행동으로 이어지는지 보았습니다.

렌더링된 앱을 ego-browser에서 cold start부터 보고서·초기화까지 따라갔습니다. 화면 너비 320×800, 375×812, 1280×900을 확인했습니다. VoiceOver 검증은 제외했습니다. 자동 테스트·빌드는 실행하지 않았습니다.

## 흐름 증거

| 상태 | 관찰한 행동·결과 | 학습자 영향 |
|---|---|---|
| 시작 | 질문, 가상 자료 표기, 30분 활동, 예산, 연구 시작 버튼이 보입니다. 12개 작품 카드가 있습니다. 표면 오염과 후대 덧칠 버튼은 처음부터 선택 상태였습니다. 버튼을 바꾸지 않고 시작해도 조사가 열렸습니다. | 첫 행동은 분명하지만 학생의 예측을 직접 받지 않습니다. 320px에서는 작품 목록 뒤에 입력이 밀려 있습니다. |
| 조사 | 확대·측면광·층 정보 조사를 차례로 요청했습니다. 결과 문구와 그림이 표시되고 예산이 6→5→3→0으로 바뀌었습니다. 같은 조사 버튼은 완료 상태로 바뀌었습니다. | 점수·관찰 피드백과 가상 자료의 한계는 이해하기 쉽습니다. 결과 카드에 내부 키가 노출됩니다. |
| 증거 | 관찰 3개와 가설 3개의 관계 9개가 표에 모두 미리 채워집니다. 화면에는 ‘연결하세요’라고 쓰였지만 입력·선택 버튼은 없습니다. 층 표는 값에 thin-dust, even을 노출합니다. | 학생이 근거를 스스로 연결했는지 확인할 수 없습니다. |
| 결정·보고 | 결정 라디오와 기대 효과·불확실성·가역성 칸이 있습니다. 세 칸과 선택을 비운 채 보고서 만들기를 눌러도 완료됩니다. 유지와 기본 문장들이 자동 기입됐고, 불확실성 칸에는 입력 안내 문구가 보고서에 들어갔습니다. | 과제 완료가 실제 판단과 설명을 증명하지 않습니다. |
| 완료·재시작 | 보고서에는 저장·JSON·인쇄·처음부터 다시가 있습니다. 아래 ‘완료 판정 자가점검’과 통과 문구가 학생 화면에 보이며 다음 사례로 가는 행동은 없습니다. 재시작하면 점수·관찰은 초기화되지만 초점은 시작 버튼 뒤의 섹션 제목으로 이동합니다. | 종료 뒤 학습 정리와 전이가 약하고, 키보드 재시작 때 시작 버튼이 순방향 Tab 경로에서 빠집니다. |

## 화면·조작 확인

- 너비별 문서 가로 넘침: 320·375·1280px 모두 관찰되지 않았습니다.
- 320px: 진행 레일 폭은 약 443px, 보이는 영역은 약 273px이며 내부 가로 스크롤입니다. 마지막 단계가 화면에서 잘립니다.
- 320px 초기 페이지에는 작품 카드 12개와 4,853px 높이가 관찰됐습니다. 빈 예측 오류를 띄운 상태에서는 페이지 높이가 4,908px이었고, 첫 관심 영역 입력은 문서 y≈4,022px, 작품 목록 끝은 y≈3,869px였습니다.
- 터치 표적: 시작 버튼 높이 52px, 가설 버튼 48px였습니다. 업데이트 내역은 좁은 폭에서 여러 줄로 커집니다.
- 포커스: 오류 alert에 초점이 이동하고 오류가 바로 읽히는 구조입니다. 재시작 시 초점은 h2로 이동하며 보이는 테두리는 없고, 다음 Tab은 작품 카드로 가 시작 버튼을 건너뜁니다.
- 움직임: 시작 버튼 gi-pulse는 기본 2.2초 고리 애니메이션입니다. reduced-motion을 에뮬레이션했을 때 animation이 꺼졌습니다.
- 이미지·도식: 선택한 가상 작품의 확대·측면광·층도는 표시됐습니다. 이미지 실패 복구 경로는 실행하지 않았습니다.
- 콘솔·요청 실패: 브라우저 버퍼에서 수집된 런타임 이벤트가 없었습니다. 이를 콘솔 오류 0개 또는 네트워크 실패 0개로 해석하지 않습니다. 전용 콘솔·요청 기록은 not run입니다.
- 대비 수치: CSS 토큰을 읽었지만 실제 렌더 대비 비율은 산출하지 않았습니다. not run입니다.

- EDU-UX-002 / P2: 320px에서 12개 작품 뒤 4,000px 지점에 조작 입력 배치, 단계 레일 일부 숨김

- EDU-UX-004 / P2: 보존 용어 풀이 부족, 지시와 실제 조작 불일치

## 좋은 점

- 시작 질문과 한 개의 강한 시작 CTA가 주의를 모읍니다.
- 가상 자료·실측이 아님과 실제 처리 지침이 아님을 표시합니다.
- 조사 비용과 각 관찰 방법의 한계를 문구로 안내합니다.
- 색과 함께 기호·텍스트로 지지·반박·미정을 구분합니다.
- 320px에서도 문서 전체의 가로 넘침은 없고 핵심 버튼 표적 크기는 충분했습니다.
- 줄인 움직임 환경에서 gi-pulse 애니메이션이 멈췄습니다.
- 가설을 2개 미만으로 만들었을 때 구체적인 오류 메시지와 alert 초점이 나타났습니다.

## 미실행·한계

- 실제 중학생·고등학생·교사 사용자 연구가 아닙니다.
- 화면 대비 비율, 콘솔, 네트워크 오류, 이미지 로드 실패 시 대체 경로는 not run입니다.
- 같은 조사 입력을 독립 실행에서 반복 비교하지 않아 결정성 검증은 not run입니다.
- 자동 테스트와 빌드는 실행하지 않았습니다. 소스 구현도 하지 않았습니다.
- 보존·재료 기술 내용의 전문 정확성 및 공식 교육과정 매핑은 검토하지 않았습니다.
