## 이해 확인 기록

- 지시 재진술/시작: 320px에서 가설 미선택으로 시작을 눌러 진행이 막히고, 구체적 안내에 초점이 이동했습니다. 서로 다른 가설 2개를 고른 뒤 진행됐습니다.
- 증거 회복: 첫 관계만 판단하고 다음을 눌렀을 때 누락 경고가 보였습니다. 미정을 고른 뒤에는 모형 판정·이유가 표시됐고, 다른 판정으로 바꾸어도 모형 결과와 학생 선택이 구분됐습니다.
- 결정/보고: 행동을 고르지 않으면 차단됐고, 기대 효과가 빈 상태에서도 해당 입력 칸으로 초점이 이동했습니다. 유효한 세 문구는 보고서에 입력 원문 그대로 표시됐습니다.
- 전이/키보드: 전이 버튼은 새 가상 작품과 6점으로 초기화하고 시작 버튼으로 초점을 보냈습니다. 시작 버튼에는 보이는 3px 링이 있었고 Tab은 ‘다른 가상 작품 선택’으로, Shift+Tab은 다시 시작 버튼으로 이동했습니다.
- 적응형/움직임: 320·375·1280px 각 너비에서 모든 단계의 문서 가로 넘침은 0px이었습니다. reduced-motion에서는 시작 버튼 애니메이션이 `none`, 지속 시간 `0s`로 바뀌고 정적 테두리가 남았습니다.
- 핵심 용어: 실제 청소년에게 뜻을 설명하게 하는 검사는 하지 않았습니다. 풀이 문구는 표시되지만 이해도는 미확인입니다.
