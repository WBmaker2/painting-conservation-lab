# 인터랙티브 시뮬레이션 결정

작성일: 2026-09-23
판정: not-needed — 추가 시뮬레이션·새 렌더러는 제안하지 않음.

## 학습 목표와 현재 흐름

- 목표: 가상 그림의 어두운 부분에 대해 여러 설명을 비교하고, 조사 결과와 한계를 근거로 보존 결정을 내립니다.
- 현재 변수: 가상 작품, 관심 영역, 조사 방식, 보존 결정.
- 조작: 버튼과 번호 입력. 핵심 화면은 DOM·SVG·표입니다.
- 관찰 결과: 각 조사는 텍스트와 코드 생성 도식으로 결과를 보여 줍니다.
- 설명: 결정 화면에 기대 효과·불확실성·되돌림에 관한 질문이 있습니다.
- 재시도·전이: 처음부터 다시가 있고, 다른 작품 선택도 가능합니다. 다만 새 사례에 배운 판단을 적용하는 완료 행동은 없습니다.

현재의 결정적이고 이산적인 가상 조사 흐름은 목표를 다루기에 충분해 보입니다. 우선 필요한 것은 새 시뮬레이션이 아니라 예측·증거 연결·결정 단계에서 학생이 실제 선택과 설명을 하도록 하는 일입니다. 추가 상호작용이 필요하다면 기존 DOM·버튼·표 안에서 해결할 수 있습니다.

- 모델 범위: 가상 관찰 규칙으로 생성된 설명이며 실제 작품의 상태 측정이나 현장 보존 조언이 아닙니다. 화면은 이 경계를 반복해 표시합니다.
- 재현성: 화면 안내에는 같은 숨은 상태와 조사가 같은 관찰을 반환한다고 쓰여 있습니다. 이번 감사는 서로 다른 실행에서 같은 조건을 반복 비교하지 않았으므로 결정적 재현성은 not run입니다.
- reset: ‘처음부터 다시’로 예산과 관찰이 초기화되는 것을 브라우저에서 확인했습니다.
- pause: N/A — 시간 진행이나 자동 실행 상태가 없습니다.
- step: N/A — 시간 순서의 한 변화씩 볼 상태 전이가 없습니다.
- 키보드·모바일·reduced-motion: 핵심 버튼과 화면 너비·모션 일부를 감사 보고서에 기록했습니다. 모델을 새로 구현한 테스트는 아닙니다.
- Canvas/WebGL: 사용하지 않아 적용되지 않습니다.
